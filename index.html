Trigger Setup — Required for Run Button

To enable the ▶ Run button, add a checkCommand trigger to each Google Sheet. Do this once per sheet.

For each of the 3 sheets:
1. Open the Google Sheet → Extensions → Apps Script
2. Click the clock icon (Triggers) in the left sidebar
3. Click + Add Trigger
4. Function: checkCommand
5. Event source: Time-driven → Minute timer → Every 1 minute
6. Click Save
Once set, clicking ▶ Run from this dashboard will start the upload within 60 seconds.
